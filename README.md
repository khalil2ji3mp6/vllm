# vLLM 无卡 CPU 基准

在仓库根目录运行。已安装离线环境的机器更新代码即可；首次离线安装时，将对应架构的依赖包放在仓库根目录，执行 `./install.sh`。

### 1. 整网，使用全部可用物理核

```bash
./run.sh
```

默认全机先处理图片，再做文本模板和分词。DP8 / TP1，每 DP 并发 32，每请求输入 32K token 和一张 1024×1024 JPEG，输出 1K token。结果见 `host-auto/coverage.md`。

### 2. 海光整网，只用 NUMA 节点 2、6 的 32 个物理核

```bash
numactl --cpunodebind=2,6 --membind=2,6 ./run.sh --core-sweep 32
```

适用于节点 2、6 各有 16 个可用物理核且均有本地内存的海光机器。8 个 DP 各用 4 个物理核，内存分配限定在这两个节点。需安装 `numactl`。

### 3. 单流程，比较单核和全部可用物理核

```bash
./run-stages.sh
```

结果见 `stages/stages.md`。吞吐按每秒完成的工作单位统计，例如文本前处理为请求/s，图片处理为图/s。

两个脚本均支持 `--out 目录名`。重复运行会自动创建带数字后缀的目录，保留已有结果。
